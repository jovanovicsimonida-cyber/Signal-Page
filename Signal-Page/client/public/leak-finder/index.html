R1

Can you name the specific steps where users start but don't finish?
Green Yes - we can name them and have data to back it up
Yellow We have strong guesses but have not confirmed them with data
Red We have never formally tracked where users drop off

Yellow Sort of - limited triggers or manual workarounds

A checklist, template, "reply to this," or a call link - something that reduces friction before they give up.
Green Yes - it is built in and fires automatically
Yellow Sometimes, but it is not consistent across all stall points
Red There is nothing specific built for this - users have to figure it out themselves

Not just a last-day expiry email - a sequence that accounts for whether users have hit value or not.
